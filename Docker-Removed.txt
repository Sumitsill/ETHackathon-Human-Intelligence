USAGE & COMMANDS:

    $ cd "ML MODELS/Md 1/backend"
    $ docker build -t cockpit-module1 .
  - Run container standalone on Port 8000:
    $ docker run -d -p 8000:8000 --env-file ../../.env --name module1 cockpit-module1

KEY ADVANTAGES:
  1. Base Image: `python:3.11-slim` ensures a minimal footprint (~150MB base).
  2. C++ System Tooling: Installs `build-essential` required for compiling 
     PyMuPDF and Pillow image processing headers.
  3. No-Cache Pip Installation: Avoids bloating container image size with cached wheels.
  4. Container Host Binding: `--host 0.0.0.0` allows binding across Docker network bridges.

EXACT CODE:
```dockerfile
FROM python:3.11-slim

WORKDIR /app

# Install system dependencies required for pymupdf and pillow
RUN apt-get update && apt-get install -y --no-install-recommends \
    build-essential \
    && rm -rf /var/lib/apt/lists/*

COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

COPY . .

EXPOSE 8000
CMD ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "8000"]
```
